# UI Templates

Store small PNG screenshots of UI elements here.

Recommended naming:

- `reel_marker.png`
- `comment_button.png`
- `comment_input.png`
- `close_comment.png`

Keep each template tightly cropped around the visual element. Avoid capturing large sections of the screen so multi-scale matching remains reliable.

Do not commit screenshots containing personal information, private messages, account details, or credentials.
