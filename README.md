# Reel UI Automation

Screen-based Reel UI automation using Python, OpenCV, and PyAutoGUI.

## Scope

- Detect the active Reel interface
- Scroll to the next Reel
- Detect and open the comment interface
- Locate the comment input area
- Enter predefined comment text
- Close the comment interface
- Repeat the UI workflow with recovery handling

The implementation is intended to work across common Windows resolutions and DPI scaling without relying only on fixed coordinates.

## Tech Stack

- Python
- OpenCV
- PyAutoGUI
- Pillow
